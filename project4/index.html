CS 180 · Project 4

(Auto)stitching Photo Mosaics

The goal of this project was to combine overlapping photographs into panoramas. In Part A, I selected matching points by hand, recovered the homographies between images, and implemented inverse warping with nearest-neighbor and bilinear interpolation. I then used feathering to blend the aligned images into mosaics.

Part A · A.3

Warp the Images

I implemented warpImageNearestNeighbor and warpImageBilinear using inverse warping. For each pixel in the output canvas, I apply the inverse homography, divide by the homogeneous coordinate, and sample the source image. This fills valid output locations directly rather than leaving gaps between forward-mapped pixels.

p_source = H_inverse * p_destination

Nearest neighbor rounds the source coordinates to the closest pixel. Bilinear interpolation combines the four neighboring pixels using their fractional distances. Locations outside the source image remain black.

For rectification, I selected the four corners of a rectangular object in each photo and mapped them to the corners of an upright rectangle. The black areas in the results are outside the transformed image, and the surrounding scene is kept visible.

Ramen

I selected the glass pane inside the restaurant door and mapped its corners to a 180 x 600 rectangle. The aspect ratio is an estimate of the pane’s shape, rather than a measured physical dimension.

The selected pane becomes upright, while the rest of the storefront changes perspective around it. The output includes the full finite warped frame. Nearest neighbor has more visible stepping along fine edges, while bilinear interpolation gives smoother transitions.

Osaka

I selected the rectangular runner billboard and mapped it to a 300 x 600 rectangle, again using an estimated aspect ratio.

The billboard becomes front-facing, while parts of the surrounding buildings stretch more strongly. In this case, the homography sends a line within the source photo toward infinity, so I used a bounded output region. The result shows the sign and nearby scene rather than the entire original frame.

Nearest neighbor was faster for both examples. It only selects one pixel, while bilinear interpolation computes a weighted average of four pixels. Bilinear took longer, but reduced the jagged appearance of edges. Neither method can recover details that were not captured in the original photo.

Part A · A.4

Blend the Images into a Mosaic

I kept the right image as the reference and warped the left image into the same coordinate system. I first calculated a canvas large enough for both images, then warped each image and its weights onto that canvas.

To avoid a hard boundary in the overlap, I gave pixels larger weights farther from the source-image edges. I combined the images using the weighted average below. This is simple feathering, with the weights determining which parts of each image contribute.

weight(x, y) = min(x + 1, width - x, y + 1, height - y)
mosaic = (weight_1 * image_1 + weight_2 * image_2) / (weight_1 + weight_2)

Pixels covered by only one image keep that image’s color. Locations with no coverage remain black. The weights determine coverage, so black pixels within a source photo are still treated as valid image content.

Roof

The mosaic extends the view across the rooftops and includes the Campanile in the distance. The roof edges provide useful landmarks for aligning the two images.

Courtyard

The mosaic joins the covered courtyard into a wider view. Repeated roof lines and columns make alignment errors easier to spot, and the feathering softens the boundary between the images.

Building

The two building facades combine into a wider view of the courtyard. The windows and rooflines continue across the overlap, while the foreground bench and trees make small local differences more noticeable.
